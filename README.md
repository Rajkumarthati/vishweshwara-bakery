# Vishweshwara Bakery (Manohar Bakery)

GitHub Pages-ready bakery website for Thungur, Beerpur Mandal.

## Publish on GitHub
1. Create a new GitHub repository, e.g. `vishweshwara-bakery`.
2. Upload `index.html`, `style.css`, `script.js`, and the `images` folder.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**, choose `main` and `/ (root)`.
5. Save. GitHub will provide the public website URL.
